# [sv](https://svelte.dev/docs/cli/overview) community add-on: [@sv-addon/editable](https://github.com/sacrosanctic/sv-addon/tree/main/packages/editable)

> [!IMPORTANT]
> Svelte maintainers have not reviewed community add-ons for malicious code! Use at your discretion.

## Usage

To install the add-on, run:

```shell
npx sv add @sv-addon/editable
```

## What you get

Scaffolds editable component templates (requires SvelteKit).
