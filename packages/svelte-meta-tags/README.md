# [sv](https://svelte.dev/docs/cli/overview) community add-on: [@sv-addon/svelte-meta-tags](https://github.com/sacrosanctic/sv-addon/tree/main/packages/svelte-meta-tags)

> [!IMPORTANT]
> Svelte maintainers have not reviewed community add-ons for malicious code! Use at your discretion.

## Usage

To install the add-on, run:

```sh
npx sv add @sv-addon/svelte-meta-tags
```

## What you get

Integrates [svelte-meta-tags](https://github.com/oekazuma/svelte-meta-tags): adds a `Metatags` component and wires `baseMetaTags` / `pageMetaTags` into the `routes/+layout.ts` and `routes/+page.ts` respectively.

## Options

No options
