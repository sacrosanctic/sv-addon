# [sv](https://svelte.dev/docs/cli/overview) community add-on: [@sv-addon/animotion](https://github.com/sacrosanctic/sv-addon/tree/main/packages/animotion)

> [!IMPORTANT]
> Svelte maintainers have not reviewed community add-ons for malicious code! Use at your discretion.

## Usage

To install the add-on, run:

```shell
npx sv add @sv-addon/animotion
```

## What you get

Integrates [Animotion](https://github.com/animotionjs/animotion): adds `@animotion/core` and scaffolds a starter presentation (scenes, config, player and timeline routes).

Requires the `tailwindcss` and `experimental` add-ons.

## Options

No options
