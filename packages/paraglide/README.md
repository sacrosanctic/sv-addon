# @sv-addon/paraglide

A fork of the [official `sv` paraglide add-on](https://github.com/sveltejs/cli/blob/main/packages/sv/src/addons/paraglide.ts), which adds an opt-in [`reactive` option](https://github.com/sveltejs/cli/pull/1168) for reactive language switching.

Install:

```shell
npx sv add @sv-addon/paraglide
```
